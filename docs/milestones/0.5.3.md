# Milestone Contract: 0.5.3 (Pure Dynamic Synthesis, Thematic Scene Weaver & Mobile Drawer)

## Acceptance Criteria

1. **Pure Dynamic Narrative Synthesis (Zero Hardcoded Story Matrices)**:
   - Completely eliminated static candidate arrays, static branch pools, and hardcoded titles/prose across the engine.
   - Evaluates active chapter nouns, character traits, and setting dynamically to formulate 3 distinct dramatic paths (*Action*, *Plot Twist*, *Intrigue*).
   - Sequential `Path D/E/F` lettering for re-requested branches.

2. **Thematic Scene Weaver & Concrete Named Location Seeding**:
   - Classifies chapter themes (*Discovery/Anomaly*, *Stealth/Infiltration*, *Action/Confrontation*, *Forensics*) from title and content to generate rich, non-overlapping scene prose.
   - Story inception seeds concrete named world settings (`The Forgotten Sanctuary`, `The Command Module`, `The Foggy District`, etc.) into `initialLore`, eliminating `"the surrounding area"` fallbacks.

3. **Google AI Studio Gemini 3.6 & Groq LPU Discovery**:
   - Dynamic model listing queries `ListModels` API for `gemini-3.6-flash` and `gemini-3.6-pro`, self-healing deprecation errors and removing obsolete endpoints.
   - Groq multi-model selector (`llama-3.3-70b`, `deepseek-r1-70b`, `llama-3.1-8b`, `qwen-2.5-32b`).

4. **Scope & Depth-Aware Narrative Vector Engine**:
   - Story Scope selector (`Short ~3-5 Ch`, `Medium ~8-15 Ch`, `Long ~20+ Ch`) dynamically adjusting pacing and narrative velocity from Inciting Incident through Climax.

5. **Universal In-Flight Entity Harvester & Mobile Bottom Sheet**:
   - In-flight entity harvester provides 1-click detection and lore bible ingestion of newly introduced characters, locations, factions, and key items.
   - 3-state draggable mobile bottom sheet drawer (`PEEK` / `HALF` / `FULL`) with floating canvas controls and segmented `[🎨 Canvas | 📖 Reader]` navigation.

6. **Comprehensive 23-Suite / 65-Test Regression Suite**:
   - 100% test pass rate across graph DAG operations, cascade pruning, entity harvesting, thematic divergence, and zero-bleeding narrative isolation.
