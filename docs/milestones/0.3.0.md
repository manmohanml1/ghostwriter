# Milestone Contract: 0.3.0 (Full Webnovel Chapter Expansion & Deep Novel Engine)

## Acceptance Criteria

1. **Full Webnovel Chapter Expansion (1,200 - 2,500+ Words)**:
   - `AIGeneratorService.expandToFullChapter` transforms single-paragraph scene seeds into multi-scene, full-depth webnovel chapters with dialogue, environmental atmosphere, internal monologues, and cliffhanger endings.
   - User can select chapter focus beats: *Balanced Multi-Scene*, *Action & Confrontation*, *Character Dialogue & Drama*, *Forensic Investigation*, or *Shocking Cliffhanger*.

2. **Sequential Scene Streaming (`⏩ + Write Next Paragraph`)**:
   - Allows sequential paragraph continuation directly onto the active chapter without forcing a branch on every sentence.

3. **Chapter Word Count & Goal Meter**:
   - Live word count tracker and goal gauge towards standard published novel chapter lengths (1,500w – 2,500w).
   - Dynamic reading time calculations (`~8 min read`).

4. **LNReader-Style Webnovel Reader Experience**:
   - 4 customizable reading themes:
     - 🌑 `DARK_SLATE` (Midnight Dark)
     - 🖤 `OLED_BLACK` (Pure AMOLED Black)
     - 📜 `WARM_SEPIA` (Vintage Book Paper)
     - 📄 `NOVEL_PAPER` (Clean Crisp Light)
   - Dynamic font size adjustment (`A-` / `A+`, 14px to 24px) with persistent preference.
   - Slide-out Table of Contents drawer for jumping between chapters and branches.

5. **Production Build & Verification**:
   - Zero-cost operation maintained.
   - Clean compilation with exit code 0.
