# Milestone Contract: 0.4.0 (Multi-Provider Auto-Failover & Rate Limit Defense)

## Acceptance Criteria

1. **Cascading Tri-Provider Failover Architecture**:
   - **Primary Engine**: Google AI Studio (Gemini 2.5 Flash).
   - **Secondary Failover Engine**: Groq (Llama 3.3 70B Versatile @ 300 tokens/sec).
   - **Offline Engine**: Dynamic Heuristic Progression Engine ($0 cost, 0 latency).
   - Automatic silent failover on HTTP 429 (Rate Limit Exceeded) or network failure.

2. **Live AI Health Status Monitor**:
   - Visual telemetry status pill in the top header displaying the currently active provider:
     - `🟢 AI: Gemini Flash`
     - `⚡ AI: Groq (Llama 3.3)`
     - `💾 AI: Smart Offline Engine`

3. **Multi-Key BYOK Settings & Connection Tester**:
   - Dedicated `⚙️ AI Keys` modal supporting individual Gemini & Groq keys stored locally.
   - Built-in `⚡ Test Connection` diagnostics calculating roundtrip API latency (ms).

4. **Production Build & Zero Cost Invariant**:
   - Clean compilation with exit code 0.
   - All cloud operations run strictly within free-tier quotas.
