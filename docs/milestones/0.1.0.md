# Milestone Contract: 0.1.0 (Local Narrative DAG & Visual Story Canvas)

## Acceptance Criteria

1. **Narrative DAG Graph Data Model**:
   - `DecisionTree` / `StoryTree`, `TreeNode`, and `TreeEdge` interfaces strictly typed in `@ghostwriter/contracts`.
   - Cycle detection algorithm prevents creating edges that violate acyclic invariants.

2. **Visual Story Canvas**:
   - Interactive SVG/Canvas rendering of branching story trees with dynamic layout.
   - Smooth pan and zoom support with mouse and touch gestures.
   - Distinct visual states for active storyline, exploring branches, pruned timelines, and canon/winner chapters.

3. **Node Operations & Editing**:
   - Create new branch from any active paragraph/chapter node.
   - Edit chapter title and markdown body in the inspector.
   - Prune abandoned timelines.

4. **Bundled Starter Fixtures**:
   - Includes rich offline starter trees:
     1. Cyber-Noir Branching Narrative (The Neon Protocol).
     2. Architecture Decision Tree (Evaluation of Monolith vs. Microservices).

5. **Local-First Persistence**:
   - Automatically saves active story edits to `localStorage` / `IndexedDB`.
   - Zero network or backend API dependency required.
