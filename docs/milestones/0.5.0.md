# Milestone Contract: 0.5.0 (Real Cloud Engine, DAG Operations & Mobile Navigation)

## Acceptance Criteria

1. **Remote GitHub Repository & Versioning**:
   - Official remote linked at `https://github.com/manmohanml1/ghostwriter`.
   - Conventional Commits, branch protections, and semantic tagging workflows.

2. **Automated CI/CD Pipeline & Regression Suite (`.github/workflows/ci.yml`)**:
   - 10-scenario end-to-end regression test suite executing before builds and in CI.
   - Production Angular build and bundle output verification.

3. **Cloud Database Schema & Multi-Account Isolation (`infrastructure/supabase/schema.sql`)**:
   - Live PostgreSQL tables for `stories`, `tree_nodes`, `tree_edges`, and `lore_entities`.
   - Row-Level Security (RLS) policies isolating user workspaces (`auth.uid() = user_id`).
   - Deterministic UUID stability for in-place story updates and zero primary key collisions across 50+ users.

4. **Interactive Graph Operations & Action Safeguards**:
   - 1-Click AI Undo snapshot and revert.
   - Recursive cascade branch pruning.
   - Divergence warning modal with options to cascade prune or permanently delete child branches.

5. **Responsive Mobile Navigation**:
   - Persistent top-bar pills (`☁️ Cloud`, `✍️ Edit`, `☰ Menu`) and drawer access to all studio controls.

6. **Production Build Verification**:
   - Monorepo builds cleanly with exit code 0.
