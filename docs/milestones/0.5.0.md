# Milestone Contract: 0.5.0 (GitHub Remote Integration, CI/CD & Cloud Sync Engine)

## Acceptance Criteria

1. **Remote GitHub Repository**:
   - Official remote linked at `https://github.com/manmohanml1/ghostwriter`.
   - Full branch history, README documentation, and release tags (`v0.4.0`, `v0.5.0`) pushed to remote origin.

2. **Automated CI/CD Pipeline (`.github/workflows/ci.yml`)**:
   - Automated checks running on `push` and `pull_request` to `master`.
   - Production Angular build and bundle output verification.

3. **Cloud Database Schema (`infrastructure/supabase/schema.sql`)**:
   - PostgreSQL tables for `stories`, `tree_nodes`, `tree_edges`, and `lore_entities`.
   - Row-Level Security (RLS) policies protecting authenticated author workspaces while allowing public reading of published stories.

4. **Production Build Verification**:
   - Monorepo builds cleanly with exit code 0.
