# Milestone Contract: 0.5.2 (Security Hardening, Dynamic Versioning & Branch Protection)

## Acceptance Criteria

1. **Protected Custom Backend Credentials**:
   - Form fields in `AuthModalComponent` are masked and blank by default with clean placeholders.
   - Internal Supabase project URL and publishable API keys are never exposed in public UI inputs.

2. **1-Click Custom Backend Reset**:
   - Added dedicated `[↺ Reset]` action allowing self-hosted / local Docker users to revert to the default cloud backend cleanly with one click.

3. **Dynamic UI Version Binding**:
   - Top navigation bar version badge is dynamically bound to `environment.version` and displays `v0.5.2`.

4. **GitHub Master Branch Protection**:
   - Enforced strict branch rules: force pushes and branch deletions are blocked, and required CI status checks (`build-and-test`) must pass before merges.

5. **Expanded 13-Test Regression Suite**:
   - Full test coverage covering graph DAG traversal, cascade pruning, 1-click undo snapshots, multi-account UUID isolation, custom backend security masking, and Markdown manuscript export.
