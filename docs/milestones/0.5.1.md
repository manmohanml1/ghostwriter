# Milestone Contract: 0.5.1 (Cascade Branch Pruning, In-Place Cloud Sync & End-to-End Regression Suite)

## Acceptance Criteria

1. **Recursive Cascade Branch Pruning**:
   - Pruning any parent chapter automatically cascade prunes all child, grandchild, and downstream descendant branch nodes.
   - Clean deletion purges nodes and connecting edges without leaving dangling references.

2. **Parent Divergence Safeguard & Action Dialog**:
   - Selecting parent chapters with active children triggers glowing amber highlights on AI writing actions.
   - High-contrast confirmation modal provides 1-click options to cascade prune or permanently delete downstream child branches.

3. **1-Click AI Undo Snapshot**:
   - State snapshot captured prior to expansion, enabling instant 1-click prose restoration via `[↺ Restore Previous Text]`.

4. **Multi-Account PostgreSQL Isolation (50+ Users)**:
   - User-scoped deterministic RFC-4122 UUIDs guarantee atomic updates and zero ID collisions across concurrent user accounts.
   - In-place story update resolution (`isUUID`) prevents duplicate database records.

5. **Mobile Navigation Suite**:
   - Persistent top-bar quick pills (`☁️ Cloud`, `✍️ Edit`, `☰ Menu`) and full slide-over drawer for all studio controls on mobile viewports.

6. **End-to-End Regression Test Suite**:
   - Native Node.js test runner executing 10 automated graph, state, and security test scenarios before build and in CI.
