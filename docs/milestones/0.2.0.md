# Milestone Contract: 0.2.0 (AI 3-Way Generator & Interactive Reader Mode)

## Acceptance Criteria

1. **AI 3-Way Story Generator**:
   - `AIGeneratorService` implemented with Gemini Flash 2.5/3 API client.
   - Zero-cost smart offline heuristic generator provides instant 3-way continuations (*Action*, *Plot Twist*, *Intrigue*) with zero API key requirement.
   - Supports user BYOK (Bring Your Own Key) saved strictly in local browser storage.
   - Interactive suggestion cards with one-click adoption to canvas.

2. **Choose-Your-Own-Adventure Reader Mode**:
   - `StoryReaderComponent` renders the active narrative path with clean novel typography.
   - Interactive branch choices rendered at the end of each chapter.
   - Live rewinding: click any earlier chapter in the breadcrumb trail to explore alternate timelines.

3. **Character & World Lore Bible**:
   - `LoreBibleComponent` allows creating and managing characters, key relics, locations, and factions.
   - Lore entities are automatically injected into AI prompts to prevent hallucinated plot contradictions.

4. **Style & Tone Controls**:
   - `StyleControlsComponent` enables real-time adjustments for Genre (*Cyberpunk*, *Noir Mystery*, *Dark Fantasy*, *Hard Sci-Fi*, *Gothic Thriller*), Pacing, and Tone.

5. **Production Build & Zero-Cost Operation**:
   - Compiles cleanly with zero errors.
   - Operates 100% on free-tier / client-side storage.
